# Interface copy

Reference copy for the [mogi experience](experience.md), in English ([ADR 0002](../adr/0002-english-interface-and-documentation.md)). Read before writing or changing any text, title, button or accessible name. Tone: short, in the vocabulary players use in the Lounge.

## Capitalization

HIG **Title Case** for commands: buttons, toolbar and menu items, list rows that act or navigate, titles of sheets, pages and alerts, segmented control labels. Articles, coordinating conjunctions and prepositions of up to four letters stay lowercase except in first and last position ("Restore from Backup", "Add the Tier to Submit"). Proper names and literals stay as they are ("Copy !submit", "Mogi on Rails", "FFA", "IGN"). Derived titles go through `titleCase` (`lib/format.ts`).

**Sentence case** for everything else: radio options ("Yes, points carried over"), descriptions, group notes and titles, placeholders, toasts (no final period), inline errors, row content ("Race N · after the race", "Table after race N"). A sentence that cites a button uses its exact name ("Use Save Image."). Check: [Design checks](design-system.md#design-checks).

## Stored copy

Some text is saved with the data and later matched by value, so a backup keeps the wording it was saved with: race reviews (`lostInferredNumberReview`, `sequenceConflictReview` in `origin-scope.ts`) and a batch item's identical-screenshot notice (`identicalDuplicateNotice`, `lib/captures/intake-review.ts`). Rewording one keeps every shipped wording recognized: the earlier text goes into `earlierReviews` or `identicalOpenings`, and the tests that pin the shipped wordings (`sequence.test.ts`, `intake.test.ts`) gain the new one. Error messages matched by `staleActionDestinations` (`lib/mogi/recovery.ts`) are never stored, but a reworded message rewords its key in the same change.

## Reference copy

Copy that carries a decision or appears in more than one place. The rest lives only in the screen's component, which is the source: Storage with backups and Restore (`components/storage-panel.tsx`, `components/storage-mogi.tsx`, `components/backup-panel.tsx`, `components/automatic-backups.tsx`), updates (`components/offline-panel.tsx`), Players (`components/mogi-players.tsx`), Mogi Settings and Screenshots (`components/mogi-settings.tsx`, `lib/mogi/capture-label.ts`), viewer (`components/ui/capture-viewer.tsx`), Review Screenshot (`components/captures/`). The UI says "screenshot" for a capture, in every title, button, label, toast and message; "image" names only the exported table (Save Image, Copy Image), "Capture" only the Switch button and "photo" only the Photos app. The UI also says "results screen" for the game's results, "in-game points" for native points and "game total" for the game cumulative.
