# Issue tracker: GitHub

Issues and specs live in the GitHub Issues of `barradasotavio/mogi-on-rails`. Use the gh CLI with `--repo barradasotavio/mogi-on-rails`.

- Publishing a ticket or spec: create a GitHub issue.
- Reading a ticket: read its body, labels and comments.
- Multiline descriptions and comments: use `--body-file`.
- Link related issues and record blocking relationships.
- Labels: [triage-labels.md](triage-labels.md).

Requests arrive as issues only; PRs carry implementation.
