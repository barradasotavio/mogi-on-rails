# Triage labels

When a skill mentions a triage role, use its label, even without the triage skill installed.

| Role / GitHub label | Meaning |
| --- | --- |
| needs-triage | Requires maintainer evaluation |
| needs-info | Waiting for more information |
| ready-for-agent | Fully specified; ready for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Declined |
