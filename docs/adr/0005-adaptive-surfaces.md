# Adaptive surfaces and floating inspector

Details and tasks open in one surface component, the Sheet, which adapts to the size class: a large or medium drawer on iPhone; on iPad and desktop, an inspector for details and a centered window for what needs attention. The inspector floats over the content at every width, even from 1280 px where it would fit pinned: pinning it would narrow the column and make the table swap for the race list just because a detail opened.
