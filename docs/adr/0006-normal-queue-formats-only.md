# Normal queue formats only

The app supports only the Lounge 12p normal queue formats: FFA, 2v2 and 3v3. 4v4 and 6v6 are left out even though the LT and the Lounge rules mention them, because they don't appear in the normal queue and each extra format multiplies the cases for teams, tags and export. War and Squad Queue get nothing specific; an SQ can be recorded as a normal-queue mogi, with no guarantee that the export works.
