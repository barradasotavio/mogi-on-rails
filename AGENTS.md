## Agent skills

### Issue tracker
Before reading or publishing issues and specs, read `docs/agents/issue-tracker.md`.

### Triage labels
Before classifying issues, read `docs/agents/triage-labels.md`.

### Domain docs
Before exploring or changing domain concepts, read `docs/agents/domain.md`.

### Validation
Before adding a test or check, running tests, integrating changes, or debugging Playwright across worktrees, read `docs/contracts/quality.md`. New tests and checks are minimal: they meet its criteria and fit its budgets.

### UI
Before changing screens, navigation, UI components or theme tokens, read `docs/contracts/experience.md` and `docs/contracts/design-system.md`. Before writing or changing UI text, read `docs/contracts/copy.md`. A user-visible change adds its release-note line: see `docs/contracts/experience.md#release-notes`.

### Engine
Before changing `packages/engine`'s public API, read `docs/contracts/engine.md`.

### Captures and scoring
Before changing the capture sequence, numeric readings, team captures or race drafts, read `docs/contracts/capture-sequence.md`. Before changing proven totals, corrections or reconstruction, read `docs/contracts/reconstruction.md`. Before changing points, `!submit` or credit, read `docs/contracts/scoring.md`.

### Backup and offline
Before changing backup or restore, read `docs/contracts/backup.md`. Before changing the service worker, offline cache, installation or updates, read `docs/contracts/offline.md`.

### OCR
Before changing recognition, crop regions, model assets, or OCR diagnostics, read `docs/contracts/ocr.md`.

### Docs map
Before looking for a contract not listed here, or adding, moving or deleting Markdown, read `docs/README.md`.
